# 《九点熄灯》角色立绘提示词

> 给 AI 画图工具用的。每个角色有：设定、外貌、英文提示词（直接粘贴）、表情清单。
> 提示词用英文，因为大多数画图模型对英文理解更好。中文只用来解释设计意图。

换性别时，只改提示词里的 `male/female` 和 `man/woman` 两处，其他不用动。

### 全局风格（每次生成都加在最前面）

```
Japanese courtroom-mystery visual novel character sprite, waist-up, front three-quarter view, clean bold black outlines, flat cel shading, slightly exaggerated expressive face, soft saturated colors, modern Chinese office setting, plain solid light gray background, centered, 2D game asset, high detail
```

> 这里故意没写某款游戏的名字，避免画风和现有作品撞得太近。如果你以后要商业发行，这样更安全。

### 全局负面提示词（每次都加）

```
photorealistic, 3d render, blurry, extra fingers, deformed hands, text, letters, watermark, logo, multiple people, cropped head, busy background, full body
```

### 通用约定（保持全员风格一致，这是最关键的）

1. **统一画布**：竖版 1024×1536，半身（腰部以上），脸在画面上三分之一处。
2. **统一背景**：纯浅灰色。生成后用抠图工具（如 rembg）去背景，存成透明 PNG。
3. **统一光线**：柔和的顶光，没有强烈的明暗对比。
4. **外包三人（邵晓阳、陆诚、黎默）平时都是便装**，立绘按各自的外貌设定画。**橙色外包外套单独画一件"可叠加"的图层**（透明背景，能套在任何一个外包角色身上）：剧本规定出 17 层办公区必须穿，袭击场景里会用到。其他人不要穿大面积橙色。郑岑穿红衬衫，红和橙要拉开色相，别画得太像。
5. **衣服上不要让 AI 生成文字或 logo**，后期自己加。
6. **表情用同一个角色的参考图改**，不要每次重新生成，否则脸会变。做法见文末。

## 表情怎么批量生成（保证脸不变）

1. 每个角色先出一张**满意的"平常"表情**，定为这个角色的标准图。
2. 其他表情用这张图当参考，再生成：
   - Midjourney：用 `--cref 标准图链接`
   - Stable Diffusion：用 IP-Adapter 或训练一个这个角色的 LoRA
   - GPT 图像、Flux Kontext 等支持"图生图编辑"的模型：上传标准图，提示词写 `same character, same outfit, same pose, only change the facial expression to <表情>`
3. 表情后缀（加在角色提示词最后）：

| 表情 | 后缀 |
|---|---|
| 慌张 | `panicked, sweating, wide eyes` |
| 生气 | `angry, furrowed brows, clenched teeth` |
| 难过 | `sad, teary eyes, downcast` |
| 心虚 | `guilty, cold sweat, eyes looking away` |
| 惊讶 | `surprised, wide open eyes and mouth` |
| 坚定 | `determined, sharp eyes, lowered brows` |
| 冷笑 | `cold smirk` |
| 崩溃 | `breaking down, tears streaming, hollow eyes` |

4. 每个角色最后得到 3～5 张表情，文件名统一成 `角色id_表情.png`（比如 `lyc_normal.png`、`limo_guilty.png`），放进游戏的素材文件夹，程序会自动读取。
