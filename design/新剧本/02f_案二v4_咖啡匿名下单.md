## 八、"垃圾回收日"的提示（用户补充）

垃圾桶里的外卖单是这条线最硬的一环，而它有一个**物理期限**：11-21 凌晨 05:30 之后就没了。所以要在剧情里提前、自然地让玩家知道"周六早上清运"，同时**不能直接说"去翻垃圾桶"**。提示分三层，保证没人因为没留意而被卡死。

### 8.1 主角忽然提一下（固定，不受玩家选择影响）
**11-19 夜晚（每天结束的过场）**，林回到家，一句自述：
> 楼下的清运车明早又要来了。周六凌晨五点半，从来不差，吵得人睡不着。

这是一句**家常话**，玩家只当它是氛围。到 11-20 他走进巷口咖啡那条街，看到街角垃圾桶上贴着的清运告示时，这句话才被接上（见 8.2）。

### 8.2 检查与搜证处处带一句（用户要求："各方面的检查也要提示一下便利店垃圾回收日"）
| 位置 | 提示 | 门槛 |
|---|---|---|
| **巷口咖啡街区的街边垃圾桶**（热点描述） | 桶身贴着告示："本路段每周六 05:30 清运。"林想起昨晚那句话。 | 无 |
| **便利店店员**（任何一次交谈） | "门口那个桶啊，我们这条街周六一早才有人收，满得都溢出来了。" | 无 |
| **巷口咖啡店员**（11-20 14:00） | 提到单子是跑腿平台下的，没见过人；顺口一句"对面便利店门口老有人等外卖，他们家垃圾桶也是周六才清"。 | 无 |
| **小许**（分局，11-19 或 11-20） | 林提到咖啡时，小许："街边的桶是周六早上收，别的我帮不上。" | 无 |
| **老王**（物业监控室） | 聊起外面商业街：垃圾"周六一早才有人来拉"，所以前一天晚上桶都满着。 | 无 |
| **提示卡（tip）**（只在 11-20 夜晚、玩家还没找到外卖单时弹一次） | "清运日是周六早上，现在已经是周五夜里。" 不说地点，不说"去找什么"。 | 仅当没有这条证物 |

### 8.3 写作纪律
- 提示只给**时间**（周六 05:30 清运），不给**地点**（不说"去翻垃圾桶"）。
- 玩家必须自己把"点咖啡的人抽烟买烟"与"街边垃圾桶"联系起来。
- 所有提示都**无门槛**（不看好感，不看已有证物），都在 11-20 夜晚之前出现，11-21 清晨之后不再提示（桶已空）。
- 如果玩家错过垃圾桶，仍可以靠 **店员证言（红塔山＋预付卡）＋跑腿员证言＋便利店监控**拿下同一个结论，不会被锁死。
